# Environment switches

Every `VICTORY_*` variable the code reads, generated by `cargo xtask env`
from the source; do not edit by hand. A test warns when it is out of date.
"Documented" says whether the README, another page in `docs/` or
`victory.example.toml` describes it. At startup a set `VICTORY_*`
variable missing from this list is reported as read by nothing.
